# 记事修仙录 - 用户引导系统设计文档

## 概述

为新用户设计三阶段引导流程，帮助用户理解小程序的核心功能，避免误解为单纯的修仙游戏。

## 设计目标

1. **消除误解**：让用户明白这是一个个人成长工具，不是修仙游戏
2. **降低门槛**：通过引导帮助用户正确设置属性和任务
3. **随时可查**：提供说明页入口，用户有疑问时可随时查看
4. **模块化**：修仙模块可选，适应不同用户群体
5. **可跳过**：引导流程可跳过，尊重用户选择

## 三阶段引导流程

### 阶段一：欢迎页

**触发时机**：用户首次打开小程序（未完成初始化）

**页面设计**：
- 简约风格视觉（白色/浅灰背景 + 深色文字）
- 现代简洁文案
- 3个核心信息点：
  1. 这是什么：个人成长追踪工具
  2. 能做什么：设置目标、完成任务、追踪进步
  3. 为什么用：游戏化激励，让成长更有趣

**文案示例**：
```
标题：记事修仙录
副标题：用游戏化的方式，记录你的成长

• 设置个人属性和目标
• 完成每日任务获得成长
• 看见自己的进步轨迹

[开始使用]
```

**交互**：
- 点击"开始使用"进入初始化页面
- 右上角"跳过"按钮，跳过引导直接进入初始化页面

### 阶段二：初始化引导

**触发时机**：从欢迎页进入或首次进入初始化页面

**引导形式**：全屏遮罩高亮

**分步流程**：

#### 步骤1：基本信息
- 高亮：名字和年龄输入框
- 说明："首先，告诉我们你是谁"
- 操作：输入名字和年龄
- 完成条件：两个输入框都有内容

#### 步骤2：选择模式
- 高亮：模式选择区域
- 说明："选择使用模式。修仙模式会增加境界、灵力等游戏化元素，适合喜欢挑战的用户；简洁模式只保留核心的成长追踪功能"
- 操作：选择"修仙模式"或"简洁模式"
- 完成条件：选择了一个模式
- **注意**：强制选择，无默认值

**默认主题**：初始化前默认使用"轻量简约"主题（light），用户可在设置中随时切换

#### 步骤3：设置属性
- 高亮：属性设置区域
- 说明："选择一个模板快速开始，或者自己添加属性。这些是你要追踪的成长维度"
- 操作：选择模板或手动添加属性
- 完成条件：至少有一项属性

#### 步骤4：理解属性
- 高亮：已设置的属性列表
- 说明："这些属性代表你要提升的方面，完成任务会提升对应属性。你可以随时在设置中修改"
- 操作：查看属性列表
- 完成条件：点击"下一步"

#### 步骤5：设置任务
- 高亮：任务设置区域
- 说明："选择一个模板快速开始，或者自己添加任务。任务分为4种类型：每日（每天重复）、特殊（不定期完成）、应急（临时紧急）、阶段（长期目标）"
- 操作：选择模板或手动添加任务
- 完成条件：至少有一条任务

#### 步骤6：理解任务
- 高亮：已设置的任务列表
- 说明："这个工具的核心是帮你养成好习惯、追踪个人成长。完成任务会提升对应属性，让你看到自己的进步。每天坚持完成任务，你会发现自己在各个方面都在成长。任务可以在设置中随时修改和添加"
- 操作：查看任务列表
- 完成条件：点击"下一步"

#### 步骤7：完成初始化
- 高亮：完成按钮
- 说明："点击完成，开始你的成长之旅"
- 操作：点击完成
- 完成条件：初始化成功

### 阶段三：主面板引导

**触发时机**：首次进入主面板（初始化完成后）

**引导形式**：分步高亮弹窗

**分步流程**（根据用户选择的模式动态调整）：

#### 步骤1：属性区域
- 高亮：属性卡片区域
- 说明："这里显示你的各项属性，数值越高代表能力越强。点击属性可查看详情"
- 操作：点击任意位置继续

#### 步骤2：任务区域
- 高亮：任务列表区域
- 说明："这里显示你的任务，点击完成按钮可以获得属性提升"
- 操作：点击任意位置继续

#### 步骤3：修仙系统（仅修仙模式）
- 高亮：修仙等级显示区域
- 说明："完成任务还会获得灵力，灵力足够时可以突破修仙境界"
- 操作：点击任意位置继续

#### 步骤4：等级制度
- 高亮：评级显示区域（用户评级行）
- 说明："点击这里可以查看等级制度，包括属性等级和用户评级"（简洁模式）/ "点击这里可以查看完整的等级制度，包括属性等级、修仙境界、用户评级"（修仙模式）
- 操作：点击任意位置继续

#### 步骤5：每日自动更新
- 高亮：每日任务区域
- 说明："每日任务会在每天自动重置，无需手动操作。打开页面时会自动检查并更新"
- 操作：点击任意位置继续

#### 步骤6：设置和说明
- 高亮：底部 tabBar 的设置标签和右上角书本图标
- 说明："设置和说明都在这里，有疑问随时查看"
- 操作：点击"知道了"完成引导

- `theme`：当前主题标识（默认 'light'）

## 附录：自动日期更新设计

### 需求背景
原有的"每日重置"按钮需要用户手动点击，体验不够流畅。改为根据现实时间自动更新，让用户无需手动操作。

### 设计原则
1. **自动化**：根据日期变化自动重置每日任务
2. **防重复**：同一天内不会重复重置
3. **实时性**：每次打开页面或刷新时检查

### 触发时机
1. **页面加载时**：`onShow` 生命周期
2. **从后台切回前台**：`onShow` 也会触发
3. **手动下拉刷新**：支持用户主动刷新

### 检查逻辑
```javascript
// 伪代码
function checkDailyReset() {
  const today = getTodayDate(); // 获取今天日期
  const lastResetDate = wx.getStorageSync('daily_tasks_reset_date');
  
  if (lastResetDate !== today) {
    // 需要重置
    resetDailyTasks();
    wx.setStorageSync('daily_tasks_reset_date', today);
    updateUI();
  }
}
```

### 重置内容
1. **每日任务状态**：所有"每日"类型任务重置为未完成
2. **连续打卡天数**：检查昨天是否完成所有每日任务，更新连续天数
3. **属性衰减**：检查是否有属性需要衰减（超过7天未提升）

### 存储字段
- `daily_tasks_reset_date`：每日任务重置日期（YYYY-MM-DD 格式）
- `last_active_date`：最后活跃日期（用于连续打卡计算）

### 云函数调整
- `panel` 云函数：移除手动重置逻辑，改为检查日期自动处理
- 移除 `morning` 云函数（不再需要）

### UI 变化
- 主面板：移除"每日重置"按钮
- 主面板：移除"等级制度"按钮，改为点击评级行弹出

## 附录：修仙模块可选设计

### 需求背景
不同用户群体对游戏化元素的接受度不同。年轻用户可能喜欢修仙元素，而年长用户（如父母辈）可能觉得复杂。因此需要让用户自主选择是否启用修仙模块。

### 设计原则
1. **强制选择**：初始化时必须选择，无默认值
2. **完全隐藏**：不启用时，UI和逻辑都隐藏
3. **随时切换**：可在设置页随时开启/关闭

### 隐藏内容（简洁模式下）
- 主面板：修仙等级显示、灵力值、突破按钮
- 任务完成：不再显示灵力奖励
- 统计页：隐藏修仙相关统计
- 说明页：隐藏修仙系统标签页

### 存储字段
- `cultivation_enabled`：布尔值，存储在本地和云端
- 本地存储用于UI渲染
- 云端存储用于云函数逻辑判断

### 技术实现要点
1. **初始化页面**：新增模式选择步骤
2. **主面板**：根据 `cultivation_enabled` 条件渲染
3. **云函数**：根据云端配置决定是否计算灵力
4. **设置页**：添加模式切换开关
5. **休闲分区**：原占卜和备忘录页面迁移至此
6. **TabBar**：新增休闲和设置标签
7. **自动日期更新**：每次打开页面检查日期变化，自动重置每日任务
8. **等级制度弹窗**：根据模式显示不同标签页（修仙模式显示修仙境界，简洁模式隐藏）
9. **属性框样式**：紧凑卡片，默认显示名称、数值、等级，点击展开详情（进度条、等级描述）
10. **专属属性等级**：精神、意志力、心情、体质使用专属等级表，其他属性使用通用等级表
11. **默认主题**：初始化前默认使用"轻量简约"主题（light）
