# 记事修仙录

一款游戏化的个人成长管理微信小程序。把日常生活变成修仙 RPG，完成任务提升属性，看着自己的"修为"一步步增长。

## 功能特性

### 核心玩法
- **属性系统** — 像 RPG 角色一样拥有体质、学识、心境等属性，完成任务自动增长
- **修仙等级** — 从凡人到仙人的境界突破系统，积累灵力即可晋升
- **每日打卡** — 连续打卡机制，保持习惯不断档
- **用户评级** — 根据综合属性自动计算评级（E~SSS）

### 任务系统
- 每日任务 / 阶段任务 / 应急任务三种类型
- 任务可关联属性，完成后自动加点
- 自定义任务奖励规则（如：心情+5，耐力+3）

### 命理工具
- **今日运势** — 基于天干地支的每日运势推算
- **八字排盘** — 出生年月日时的四柱八字分析
- **六壬占卜** — 传统六壬课排盘
- **塔罗牌** — 在线塔罗牌占卜

### 其他
- **备忘录** — 修仙风格的记事本
- **成长记录** — 查看历史数据统计和成长曲线
- **每日提醒** — 自定义时间推送通知
- **多套主题** — 暗黑 / 古风 / 亮色 / 赛博四种风格

## 技术栈

| 技术 | 说明 |
|------|------|
| 微信小程序 | 前端框架 |
| 微信云开发 | 后端服务（云函数 + 云数据库） |
| WXML / WXSS / JS | 页面结构、样式、逻辑 |

```
│   ├── liuren/      # 六壬占卜
│   ├── memos/       # 备忘录
│   └── help/        # 使用帮助
├── components/
│   └── task-item/   # 任务卡片组件
├── utils/

│   ├── liuren.js    # 六壬排盘算法

```

## 使用方式

1. 克隆本仓库
2. 打开微信开发者工具，导入项目
3. 在 `app.js` 中替换云开发环境 ID 为你的环境 ID
4. 在微信开发者工具中部署云函数
5. 编译运行

> 需要先在微信后台开通云开发服务。
